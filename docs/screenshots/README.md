# 截图存放处

把下面 5 个文件放进这个文件夹（`D:\算法组培训\docs\screenshots\`），文件名要和表格一致，
之后提交文档里的 `📷 截图位置` 会替换成这些图片。

| 文件名 | 内容 | 是否必需 |
|---|---|---|
| `01-pubsub.png` | 两个终端同时运行：左"已发布"、右"收到数据" | 必需 |
| `02-nodes-topics.png` | `ros2 node list` / `ros2 topic list` / `ros2 topic info` 的输出 | 必需 |
| `03-video.png` | 视频播放界面（能看出是哪个视频、进度条不在起点） | 必需 |
| `04-git-log.png` | `git log --oneline --graph` 或 VS Code Git Graph | 必需 |
| `05-container.png` | 容器内 `ros2 node list` / `ros2 topic list` 的输出 | 可选 |

要求：

- 统一 PNG 格式（`Win + Shift + S` 截完直接另存为 PNG 即可）；
- 终端截图里的字号要能在 PDF 里看清，建议截图前把终端字号调大；
- 名字里的短横线是半角 `-`，不要用中文标点。
