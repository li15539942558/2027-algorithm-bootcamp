## 二、关键选型决策

### 2.1 主控为什么选 STM32F105RCT6（而不是 F103C8T6）

任务要求 **CAN1 + CAN2 两路 CAN**。STM32F103 全系只有 1 个 CAN 控制器，**做不出 CAN2**；
STM32F105/107 才有 **2 个 bxCAN**。选 **STM32F105RCT6**（LQFP64，256K Flash，72MHz，
2×CAN，3×USART+2×UART，USB OTG FS）理由：

- LQFP64 手焊/风机都好做，引脚数够（51 个可用 GPIO）；
- 相比 F107 不需要以太网（F107 的 RMII 还会和 CAN2 默认脚 PB12/PB13、USART3_RX 打架）；
- 相比 CH32V307（RISC-V）和 GD32F105，生态/资料最全，Keil/CubeMX 直接用（和你任务一、
  任务二的 F103 工程习惯一致）。

### 2.2 ⚠ 两个必须知道的引脚冲突（数据手册核实结论）

| 冲突 | 事实 | 本设计的处理 |
|---|---|---|
| CAN1 默认脚 = USB 脚 | CAN1_RX=PA11(44)、CAN1_TX=PA12(45)，**与 USB OTG FS 的 DM/DP 同脚** | CAN1 用**重映射 10**：CAN1_RX=**PB8(61)**、CAN1_TX=**PB9(62)** |
| PA9 = USB VBUS 检测 | 若用 MCU 原生 USB，PA9(42) 必须接 VBUS 才能枚举，**与 USART1_TX 冲突** | 本板 MCU 不用原生 USB：USB-C 只接 CH340C；USART1 用默认 PA9/PA10 |
| CAN2 默认脚 | CAN2_RX=PB12(33)、CAN2_TX=PB13(34)（无冲突） | 直接用默认脚 |

> 结论：CAN1 必须在固件里开 AFIO 重映射（`GPIO_PinRemapConfig(GPIO_Remap1_CAN1, ENABLE)`），
> 否则用了 CH340 的 USB 就再也起不了 CAN1。这是本板最容易踩的坑，已在原理图中按 PB8/PB9 落图。

### 2.3 电源方案

```
DC 12V 输入(端子/GH) ──► 保险丝 F1 ──► 防反接 D0(SS34) ──► VIN_12V
                                                              │
                                                     U1 TPS5430 (12V→5V/3A)
                                                              │
                                                          5V 母线 ─┬─► 3V3 轨: U2 AMS1117-3.3 (5V→3.3V/1A)
                                                                   ├─► GH1.25 座 VCC 脚（对外供电）
                                                                   └─► 电源指示灯 D2
3V3 轨 ──► MCU / CH340C / CAN 收发器 / LED / 上拉电阻
```

- 输入 12V、输出 5V@3A：TPS5430 输入范围 5.5–36V，最大 3A 连续，500kHz 固定频率（内部补偿）。
- 5V→3.3V 用线性 LDO（AMS1117-3.3，1A）：压差 1.7V，3.3V 轨总电流按 ≤0.5A 设计，
  LDO 功耗 ≈ 0.85W —— **SOT-223 需要铜皮散热**（见 5.4）。

## 四、逐模块网表（可直接照着连）

### 4.1 U1 TPS5430 电源（引脚号来自 TI SLVS632L Table 4-1）

```
引脚1  BOOT  ── C4(10nF/50V) ── 引脚8 PH
引脚2  NC    ── 悬空
引脚3  NC    ── 悬空
引脚4  VSENSE── R2(3.24k) ── GND ；同时 R1(10k) 从 5V 输出 ── VSENSE
引脚5  ENA   ── **悬空**（内部 1.5MΩ 上拉；手册明确：禁止 ENA 对地接电阻）
引脚6  GND   ── GND，且必须与底部 DAP 相连
引脚7  VIN   ── VIN_12V ；C1(10µF)+C2(100nF) 就近到 GND（≤1mm）
引脚8  PH    ── L1(15µH) ── 5V 输出 ；D1(SS34) 阴极接 PH、阳极接 GND
DAP(散热焊盘) ── GND（打 4~9 个 0.3mm 散热过孔）
5V 输出 ── C5(220µF 低ESR) + C6(100nF) ── GND
```

**校验**：Vout = 1.221V × (1 + 10k/3.24k) = **4.99V** ✓（手册 Eq.12：R2 = R1×1.221/(Vout−1.221)）

### 4.2 U2 AMS1117-3.3

```
VIN(输入脚)  ── 5V ；C7(10µF) ── GND
VOUT(2 个输出脚，逐脚都要连) ── 3V3 ；C8(22µF) + 100nF ── GND
GND ── GND
```


| 阻焊/丝印 | 绿色阻焊、白色丝印（嘉立创免费默认） |

### 5.2 线宽（按电流计算）

| 12V 输入 | **40mil (1.0mm)** | 12V→5V@3A 时输入电流约 1.3A |

### 5.4 布局规则（按手册和工艺）

1. **DC-DC 是布局第一优先级**，按这个顺序贴：
   - C1(10µF)+C2(100nF) 紧贴 U1 的 VIN(7) 与 GND(6)，**≤1mm**（手册硬性要求）；
   - D1 靠近 PH，L1 紧靠 PH(8)，让 **PH→L1→C5→GND** 环路面积最小；
   - C4(10nF) 直接跨在 BOOT(1) 与 PH 之间，走线尽量短；
   - R1/R2 分压放在 5V 输出电容旁边，**反馈线远离 PH 节点**，必要时换到底层走（手册 7.4.1-7）；
   - U1 的 DAP 正下方铺地铜 + 散热过孔（顶层地铜连到内层/底层地）。
2. **AMS1117**：输入输出电容各就近；SOT-223 的散热片脚接 GND 铜皮，铜皮面积 ≥100mm²（0.85W 功耗）。
3. **MCU**：放板子中部；去耦电容**每颗贴紧对应 VDD 脚**（<3mm）；8MHz 晶振距 OSCIN/OSCOUT ≤5mm，负载电容紧贴晶振，晶振下方与周边 1mm **不铺敏感信号、尽量不铺铜**并包地；SWD 口靠板边便于插排线。
4. **USB-C 座放板边**（左边缘），CH340C 与 ESD 靠近座子（D+/D− 短线，<20mm）；CC 下拉电阻紧贴座子。
5. **CAN 收发器靠近座子/端子**（右边缘），CANH/CANL 从收发器到座子直、短、并行等长；终端电阻靠近座子。
6. **GH1.25 座**分别放在右边缘（串口、CAN1、CAN2），USB 放左边缘，SWD 放上边缘；按键/LED 放底部用户可触区。
7. **分档放置顺序**：① 安装孔 ② 板边接插件（USB-C、GH×3、DC 输入端子）③ 主控+晶振+电源芯片 ④ 电容电阻/按键/LED 等卫星件。

### 5.5 布线顺序与要点

1. 先布 **DC-DC 环路**（VIN→C1→U1→L1→C5→GND），再布 5V/3V3 电源分配；
2. 再布 **晶振、复位、BOOT**（这四根最短最敏感）；
3. 再布 **USB D+/D−**（等长 10mil）；
4. 再布 **CANH/CANL**（并行、等长、间距 ≥3W）；
5. 最后布 UART/按键/LED 等低速信号；
6. **底层 GND 铺铜**，U1 DAP、AMS1117 散热片、各去耦电容地脚、CAN 收发器地脚附近打**缝合过孔**；
7. 铺铜后跑 **DRC**，逐条清：间距、短路、悬空、未连接、丝印压焊盘；
8. **丝印**：标 USB/串口/CAN 座子的引脚名、LED 极性 +/−、板名与版本（如 `RM-MINISYS-F105 V1.0`）、
   BOOT0 跳线含义。

```bash
# 0) 版本门禁与连接确认
easyeda update --check --exit-code

# 1) 器件身份解析（把 C 编号变成库身份，不靠猜）

easyeda blocks search ams1117

easyeda sch block-apply block.ch340c_usb_serial --project <P> --doc <页>
easyeda sch block-apply block.led_indicator_gpio --project <P> --doc <页>
easyeda sch block-apply block.tactile_boot_reset --project <P> --doc <页>

# 3) TPS5430 / MCU / CAN 模块：本地连接图 → 计算几何 → 组合 → 受保护队列
easyeda sch lib-layout --from layout-input.json --out composition.json
easyeda sch compose   --from composition.json --out plan.json
easyeda sch apply plan.json --dry-run
easyeda sch apply plan.json --yes

# 4) 原理图验收（四阶段硬门）
easyeda sch gate --strict --json
easyeda sch export-image --out sch.png

# 5) PCB：从原理图建板 → 导入 → 布局 → 板框 → 布线前门 → 布线 → 铺铜 → 终检
easyeda pcb new-board --project <P>
easyeda pcb import-changes --project <P> --doc <PCB页>
easyeda pcb stage set-assembly reflow        # 或 hand（手焊）
easyeda pcb place-constrained --project <P>

easyeda pcb save
```
